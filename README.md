# Create: POSTMORTEM

An addon mod for [Create](https://modrinth.com/mod/create) that aims to make the mod harder and add more endgame content.

Used [StaticFX's Create Addon](https://github.com/StaticFX/create-addon-template) template to make this.

## Planned Features

- **Steam Engine Rework** with more SU for engines above Level 9 and a pressure system.
